# Archived English summary

This repository is intended for Chinese-speaking macOS users. The maintained
documentation is the Chinese [README](../README.md).

It is an unofficial, open-source builder and reversible installer for creating
a Simplified Chinese localization patch for the Steam macOS edition of Sid
Meier's Civilization V. The repository contains code only and does not
distribute game text, Steam depot data, fonts, or generated patches.
